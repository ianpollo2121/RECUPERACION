Guía Paso a Paso
Aprende a crear una página web
1. Materiales Necesarios
  • Computadora
  • Editor de código
  • Teclado
  • Mouse
  • Navegador web
  • Conexión a Internet
 2. Procedimiento
  1. Abrir el editor de código.
  2. Crear un archivo nuevo.
  3. Guardar el archivo con extensión .html.
  4. Escribir la estructura básica de HTML.
  5. Agregar un título a la página.
  6. Agregar el contenido utilizando etiquetas HTML.
  7. Guardar los cambios y abrir el archivo en un navegador.
 3. Glosario
HTML
HTML define la jerarquía y disposición de los elementos en la página, usando etiquetas o tags encerradas entre corchetes angulares < >

Etiqueta
Las etiquetas son marcas que delimitan elementos de contenido, como párrafos, títulos, imágenes o enlaces, y le indican al navegador cómo deben mostrarse esos elementos. Cada etiqueta generalmente tiene una etiqueta de apertura y una etiqueta de cierre,

Navegador
Un navegador web (o web browser) es un software que permite al usuario ingresar a sitios web mediante direcciones URL o enlaces. Interpreta el código fuente de las páginas (HTML, CSS, JavaScript) y presenta el contenido de forma ordenada y accesible.

Programación
Un algoritmo es una secuencia de pasos lógicos, claros y finitos diseñados para resolver un problema o realizar una tarea específica. En programación, los algoritmos son fundamentales porque guían a las computadoras sobre cómo procesar datos y ejecutar acciones de manera eficiente.
